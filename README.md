# TailsCare

A modern web application for pet owners to monitor nutrition, weight, and activity levels for cats and dogs.
The project is designed with a focus on scalability and a multilingual experience (supporting English, Russian, and more in the future).

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Data Fetching:** Tanstack Query (React Query)
- **Database & Auth:** Supabase
- **ORM:** Prisma
- **Validation:** Zod
- **Package Manager:** Yarn 4 (Berry)

## Getting Started

### Prerequisites

- Node.js (Latest LTS)
- Yarn 4 (`corepack enable`)

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/IharStaliarou/TailsCare.git](https://github.com/IharStaliarou/TailsCare.git)
   ```
2. Navigate to the project directory:
   ```bash
   cd TailsCare
   ```
3. Install dependencies:
   ```bash
   yarn install
   ```
4. Start the development server:
   ```bash
   yarn dev
   ```
